另外两种建组方式
分界点前后
在判定卡或改造计划里点「对比分界点前后」：分界点之前的任务自动进 A 组，之后的进 B 组。
实验两臂
任务模式实验或评测中心的结果页 →「在任务中心对比」：两臂直接成为 A、B 组。
导入 kit 的评测结果
导入 baseline/ 和 v1/ 下的 results.jsonl，作为 A、B 两组。
点「对比」之前就提示
A 和 B 之间改了 2 处：产品模式（普通版 → 极速版）和环境（现网 → 测试）。差异不能只归因于一处改动。
