# Archive restoration workspace
Run go test -run TestUserReplay -v for the user's repro, whose data is embedded as a JSON replay. Run go test ./... for visible compatibility checks.
NewArchive creates an empty in-memory filesystem. Apply(entries) stages a whole ordered batch on a private clone; any failure leaves the original unchanged. Each Entry has Path,Kind,Target,Body,Mode. Paths are relative slash paths normalized with dot/parent handling. Absolute paths, backslashes, NUL and escape above root are errors. The root cannot be an entry. Mode is 0..0777.
File entries replace content. Directory entries create directories. Parent directories are created as needed with mode 0755; existing non-directory parents are errors. A nonempty directory cannot be replaced by a file or link. Entries and returned bodies must never alias caller-owned mutable slices.
remove deletes the exact path and all descendants separated by slash; similarly named siblings survive. Removing a nonexistent subtree is allowed.
Symlinks retain target text and resolve relative to the directory containing the symlink, including targets with parent segments. Symlinks may occur in any traversed path component. Reads follow links, reject cycles and root escapes, and require a final file. Stat does not follow the final symlink. Root-relative symlink targets are not supported.
Hardlink Target is archive-root-relative and must resolve to a file at the instant that entry is applied. It materializes an independent file snapshot using the hardlink entry's mode. Later replacement/removal of the original does not affect it. The exported entry is a regular file, with empty Target and captured Body.
Entries, List, Difference and Tar order names by exact Go string byte order, case-sensitive. No locale folding. Digest frames every ordered entry field as byte length, colon, bytes and SHA256; fields are Path,Kind,Target,decimal Mode,Body.
Tar uses zero metadata timestamps and PAX (including Unicode paths). Import supports regular files, dirs, symlinks, hardlinks and applies the complete archive atomically. Clone is independent; Replay unmarshals a JSON array then Apply. List returns direct children; Difference emits add/remove/modify by normalized exact path. Change only source files and preserve these standard-library workflows.
