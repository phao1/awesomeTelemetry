# Coalesced loads
Flights(loop,loader,ttl=5); loop is the supplied deterministic Loop. No threads, real timers or randomness.
subscribe(key,callback) returns an idempotent cancel function: True once while callback remains unpublished, False thereafter. Cancelled subscribers receive nothing. Duplicate callback objects are separate subscriptions.
loader(key,complete) runs in a deferred job and returns an idempotent cancellation function. It may complete synchronously during start, or later, or invoke complete multiple times. It does not throw. A loader is shared by active same-key subscribers until retired or completed. Different keys are independent.
complete(error,value): error is None on success or a string on failure. Only the first completion of a live flight counts. Subscriber callbacks always run in separate deferred jobs, with fresh deep copies of value; mutation by one subscriber cannot affect another or cached data. A throwing callback is isolated by Loop and cannot prevent others.
Cancel-last retires the flight, invokes its loader cancellation once if started, and permits a replacement flight immediately. If cancelled before start, loader must never start. Stale completion cannot remove or cache over a replacement flight.
Success is cached for ttl clock units from completion; cache hit iff now < completion+ttl. ttl=0 disables caching. Cache hit delivery is deferred and cancellable. Errors are never cached. Cache hit subscriptions do not extend TTL.
invalidate(key) evicts cache, retires any current loader and defers invalidated callbacks for its subscribers. Pending deliveries from a completed flight or cache hit retain their captured result. A new subscription begins a new generation immediately.
close() is idempotent. It retires all live loaders, empties cache, and changes every unpublished callback (including already queued successes and cache hits) to exactly one deferred ('closed',None) delivery. Subscribers already cancelled receive nothing. After close, subscribe returns a cancellable deferred closed delivery. Completed/published callbacks are never called again.
All stale scheduler jobs and loader callbacks must be harmless. callbacks receive (error,value), with value None for invalidated/closed. Cancellation never calls a subscriber callback. Run python3 -m unittest test_flights.py.
