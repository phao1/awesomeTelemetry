# Versioned range envelope
Envelope(input,compare) returns ordered, disjoint half-open pieces of the union of valid spans. Ignore empty/reversed spans. Coordinates and sequences are immutable integer tokens, including negative tokens. Their ordering is given only by compare. The comparator may implement any strict total order; distinct tokens compare nonzero. Native numeric order is only the default example. Do not do arithmetic on token values.
At every coordinate the winner has greatest Sequence according to compare; equal Sequence uses the lowest original input ordinal. Tombstones compete like values and MUST remain in output. Output includes the winner's original Ordinal, Sequence, Value and Tombstone.
Coalesce adjacent pieces only when their winning original ordinal is identical. Equal values from different ordinals remain separate. Gaps remain gaps. Empty output is nil. Never mutate input.
compare is injected and counts every coordinate or sequence ordering comparison. All such comparisons must use it (equality tests of previously compared event coordinates and ordinals may use native equality). It implements a deterministic strict total order without subtraction overflow, used for both endpoints and sequence priorities. No real clock or randomness.
Required work O(n log(n+2)+k), space O(n+k); at most 96*n*ceil(log2(n+2)) comparisons for n input spans. A full scan of all spans per endpoint is forbidden, even if comparisons are bypassed with native operators. Input order is arbitrary. An endpoint belongs to intervals starting there and excludes those ending there. Run go test ./... .
