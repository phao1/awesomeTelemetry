# 任务中心重构实施与验收清单

日期：2026 年 10 月 25 日。状态：主流程已实现，增强项继续跟踪。

本清单以 [design.md](design.md) 为准。完成项以实际代码、自动测试和页面证据为依据；未勾选项为未完整实现或未完整验收，不能解释为已交付。既有功能复用不代表重新验证了全部历史能力。完整交付记录见 [implementation.md](implementation.md)。

## 阶段零 固定开发基线

- [x] 固定当前分支与已有本地监控改动，分别记录提交身份和工作区差异。
- [ ] 验证原型归档可恢复，但不直接恢复为生产工作区。
- [x] 记录任务相关真实样本的来源、格式、身份和可用能力；开发 fixture 进行脱敏。
- [x] 记录构建、类型、测试、lint、请求和存储基线。
- [x] 隔离复测大正文代理测试中曾出现的 ECONNRESET，确认是否属于基线问题，不能以更改断言消除失败。
- [x] 对数据库增长超过旧有稳态目标的问题单独归因，不自动删除用户数据。
- [x] 确认当前用户授权的 Codex 监控继续开启，未授权的抓包与模型调用不被打开。

退出条件：代码、数据和测试结果可追溯；能区分已有问题、原型问题和正式重构改动。

## 阶段一 冻结任务与来源契约

### 任务锚点

- [x] 明确任务在第一阶段锚定主会话，保留独立的 Session、TeamRun、TeamTask。
- [x] 定义主会话、明确子会话、待归属子会话、孤立记录和关系冲突的读取规则。
- [x] 定义同一主会话增加子 Agent 时任务身份不变。
- [ ] 定义逻辑活动到原始事件的一对多映射，以及三种读法共用的选择身份。
- [x] 定义按事件锚点读取附近窗口的有界接口、失效原因和旧链接恢复规则。
- [ ] 明确模型尝试、重试、工具结算与轮次结束的分别表达。
- [x] 为缺少 thread_source 的 Codex 代际形状补根解析用例，检查是否误选叶节点。
- [x] 明确角色与昵称不能作为身份，父子关系不能替代通信。
- [x] 定义工作目标改变、多个主会话重复尝试与人工归组的边界；不在本轮自动猜测业务任务。

### 来源与导入

- [x] 定义 collected 与 imported 两种正式进入方式。
- [x] 将采集通道与进入方式分开，导入原始 Frida 或代理文件仍标为导入。
- [x] 分开发生、采集、导入和最近更新时间。
- [ ] 定义历史来源待确认、诊断自检与普通任务的表达。
- [ ] 定义导入批次、内容摘要、来源作用域和原始通道声明的可信度。
- [x] 定义重复文件、相同原生 ID 的异源副本及显式关联后的计数规则。

### 契约文件范围

实施前先在以下权威规范中完成字段、错误与兼容约定：

- `openspec/contracts/data-model.md`。
- `openspec/contracts/api.md`。
- 需要持久化来源信息时的 `openspec/contracts/database.md`。
- `openspec/contracts/nfr.md` 中新增任务读取投影的预算。
- 对应前端、扫描、团队与导入规格。

退出条件：任务引用、来源描述、分页与能力模型不存在相互矛盾的定义。新增 API 和字段只有在契约阶段通过后才进入实现。

## 阶段二 实现任务读取投影

- [x] 建立服务端 TaskReadModel，组合已有会话、明确关系和导入索引。
- [x] 实现采集记录与导入记录各自的任务分页与过滤。
- [x] 主会话在列表中只出现一次；子会话不重复变成独立任务行。
- [x] 保留高级原生会话检索，避免隐藏需要排障的孤立线程。
- [ ] 让缺少主会话身份的抓包或导入记录进入待关联遥测。
- [x] 通过一次有界聚合读取任务摘要，禁止前端逐行请求会话与团队。
- [x] 对拟议 `/api/tasks` 与任务摘要接口添加契约、分页、错误和大小测试。
- [x] 需要迁移时先备份并提供回退，禁止重写原始身份和正文。
- [x] 任务来源过滤不因关联导入证据而丢失原来的采集来源。

候选代码范围需要在本阶段开始时冻结：任务读取模块、已有查询层与索引、HTTP 路由注册、契约类型、同目录测试。不要同时重写播放器或抓包引擎。

退出条件：任务列表不重复，来源可解释，分页稳定，读取量有上限。

## 阶段三 建立任务中心导航

- [x] 一级导航收敛为任务中心、数据接入和设置。
- [x] 任务中心提供采集记录与导入记录视图，不把单 Agent 和多 Agent 分成两个主要列表。
- [x] 总览不再作为默认一级入口；保留少量可操作摘要和旧统计链接。
- [x] 统一菜单、命令面板、空态、面包屑和返回入口的路由模型。
- [x] 任务详情明确显示主会话、来源、发生时间、记录状态和覆盖。
- [x] 多 Agent 关系作为任务详情内的可选结构展开。
- [x] 任务默认打开执行过程，概览收进头部摘要；提供对话、执行轨迹、原始事件三种读法。
- [x] 全任务默认用成员轨迹，不能将并行会话拼成一条虚构对话。
- [x] 实现旧 session、team、mission、agent、proxy 和 frida hash 的兼容适配。
- [x] 未知或已删除身份显示明确错误，不静默切到其他任务。
- [ ] 窄屏未选任务时优先展示列表，返回后恢复筛选和滚动位置。

候选前端范围：`src/App.tsx`、`AppShell.tsx`、`hash-router.ts`、`CommandPalette.tsx`、现有会话和团队入口组件，以及新导航纯模型、i18n、样式和同目录测试。组件目录的整体搬迁延后。

退出条件：用户从一个入口找到任务，单多 Agent 不改变任务身份，全部旧记录仍可定位。

## 阶段四 统一执行过程、证据与可选回放

- [ ] 正式播放器只由任务详情挂载，旧会话和团队入口指向同一执行上下文。
- [x] 支持主会话、全任务与指定成员范围，能力不足时有明确说明。
- [x] 指定成员使用现有 agent 参数读取一页，而非过滤另一成员占据的页面。
- [x] 活动页保留游标，默认 200 条，明确已加载数量和时间边界。
- [ ] 阶段投影只使用有证据的活动类型，未知时间单独查看。
- [x] 选择步骤能进入所选遥测或来源会话，并保留返回任务的锚点。
- [ ] 成员抽屉内提供回放成员和来源入口。
- [x] 切换任务或成员取消旧请求，清理旧正文、错误和播放定时器。
- [x] 不因为快照 stamp、语言或布局变化而无条件重建播放器。
- [ ] 新数据提示可更新；显式更新暂停并保留可恢复的位置。
- [x] 保留现有来源隐私和正文懒读取限制。
- [x] 三种读法共用单条检查器，按记录类型提供有效详情；未选中不读取正文。
- [x] 实现查看证据、定位过程和父子 Agent 往返，保留原步骤与滚动位置。
- [ ] 按锚点加载缺失窗口，区分精确定位、近似上下文与不可用。
- [ ] 错误和类型筛选保留祖先上下文，命中计数不含上下文行。
- [ ] 区分窗口内搜索与全任务搜索，筛选遮挡定位目标时可临时显示并恢复。
- [x] 时间图只绘制已有时间证据，多成员泳道不隐含因果或完整关键路径。
- [x] 静态阅读支持尾部跟随；向上滚动、选旧事件及进入回放暂停跟随。
- [ ] 同一逻辑调用的多通道证据不重复累加，重建请求与实际抓包原文分别标注。

候选范围：任务回放控制器、`AgentCollabReplay.tsx`、`StageReplay.tsx` 与回放模型、现有 trajectory 组件、团队客户端、证据读取缓存及测试。旧实现只有在调用者和深链接迁移完成后才删除。

退出条件：用户能够从任务选择成员、阅读其过程、检查原文并返回；没有假空回放和隐式全量读取。

## 阶段五 整理数据接入与实时运行态

- [x] 按用户的问题解释本地日志、网络代理、CDP、Frida 和导入的适用条件。
- [x] 默认推荐受支持的原生会话监听，只有需要模型请求证据时追加代理。
- [x] 明确 CDP 的开发模式限制和 Frida 的目标适配范围，不做泛化支持承诺。
- [ ] 区分保存配置、监听器已启动、收到记录、解析结果和保存结果。
- [x] 区分任务监控范围与共享采集器的运行资源。
- [x] 界面不能展示尚未实现的精确任务级启停能力。
- [x] 默认关闭规则、当前显式运行选择和重启行为分别说明。
- [x] 按实际受影响身份合并 SSE，不让所有任务随任意一条记录变化刷新。
- [ ] patch 按 ID 替换实体，更新与缓存失效遵守作用域和版本。
- [x] 导入不启动监听、不发上游请求、不产生“正在运行”标记。
- [ ] 未归属遥测保留原始记录，并提供可检查的候选或显式关联入口。

退出条件：用户知道正在获取什么数据、采用什么通道、缺少什么，以及停止操作会影响哪些范围。

## 阶段六 全流程验收

### 用户流程矩阵

| 编号 | 场景 | 必须通过的断言 |
|---|---|---|
| T01 | 主会话独立执行 | 显示一个任务，可阅读主会话，不出现空团队要求 |
| T02 | 运行中增加子 Agent | 原任务身份和列表行不变，成员结构有证据地增加 |
| T03 | 子会话先到 | 保留待归属状态，后续关联不复制事件 |
| T04 | 无明确父关系 | 不按名称或时间自动归组 |
| T05 | 根解析代际变化 | 缺少 thread_source、父关系冲突和循环均有测试 |
| T06 | 成员超过一页 | 服务端成员查询可读取其活动，不显示假空 |
| T07 | 来源为导入 | 保留批次和格式，发生与导入时间分开，无监听状态 |
| T08 | 导入真实历史日志 | 不标为模拟，不声称当前在线 |
| T09 | 重复导入同一文件 | 可识别副本，不计为一次新执行 |
| T10 | 异源相同会话 ID | 不覆盖、不自动合并，来源作用域保留 |
| T11 | 仅有模型请求 | 进入待关联遥测，不虚构完整任务和子 Agent |
| T12 | 缺少任务或通信 | 显示未提供，不显示零完成率或零通信结论 |
| T13 | 正在回放时更新 | 历史窗口与正文稳定，只提示有新数据 |
| T14 | 快速切换任务或成员 | 旧响应不覆盖新范围，旧正文不泄漏到新任务 |
| T15 | 失效后旧请求返回 | 不能重新填回已失效缓存 |
| T16 | 重复 patch | 同 ID 成员被替换，不重复显示 |
| T17 | SSE 断开重连 | 连接与采集状态分开，有界恢复且不制造流片段 |
| T18 | 正文读取失败 | 只局部重试，不重新发送模型请求 |
| T19 | 无时间或顺序冲突 | 无虚构时间，不把相邻记录解释成因果 |
| T20 | 旧 URL 恢复 | 原会话、运行与事件身份仍可定位 |
| T21 | 单 Agent 对多 Agent 比较 | 明确任务、环境和证据差异，不能自动判胜 |
| T22 | 采集副本对导入副本比较 | 提示可能是同一执行，不当作两次独立结果 |
| T23 | 页面连接正常但代理无流量 | 不显示目标 Agent 已接通 |
| T24 | 用户只浏览历史 | 不启停通道、不安装证书、不启动 Agent |
| T25 | 窄屏成员详情 | 可以在抽屉内进入回放与来源，再返回任务 |
| T26 | 键盘与双语 | 导航、搜索、分页、回放和焦点恢复可用 |
| T27 | 部分来源能力不足 | 按能力禁用或解释，仍可阅读已保留证据 |
| T28 | 本地诊断自检 | 明确诊断标记，不计入正式任务 |
| T29 | 三种过程读法切换 | 保留任务、成员及可映射事件，无法映射不选无关记录 |
| T30 | 父步骤进入子会话再返回 | 回到原委派事件与滚动位置，无凭空交接结论 |
| T31 | 锚点在已加载页之外 | 有界加载附近窗口；缺失、删除和无权限有明确结果 |
| T32 | 错误筛选与跨视图定位 | 保留祖先但不多计错误；遮挡目标可显示并恢复筛选 |
| T33 | 模型重试后成功 | 当前状态与历史失败分别展示，工具和轮次不提前完成 |
| T34 | 日志与代理记录同次调用 | 有依据关联，多份证据保留但计数不加倍 |
| T35 | 实时阅读向上滚动 | 暂停跟随并提示新记录，回到最新由用户触发 |
| T36 | 网络原文与日志重建请求 | 明确来源和重建完整性，不将缺失请求显示为实际抓包 |
