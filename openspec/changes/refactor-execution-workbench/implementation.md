## 用户能怎样使用

1. 打开 `http://127.0.0.1:4173/#/task`。任务列表以主会话为入口；明确关联的子 Agent 合在同一个任务内。采集记录与导入记录分开。
2. 选择任务，默认阅读执行轨迹；按需切换对话或原始事件。三种读法共用同一记录身份。
3. 范围可以选主会话、全任务或指定成员。全任务展示带成员身份的记录，不拼成串行聊天。展开成员可查看明确的父子关系。
4. 选择过程中的记录，右侧检查摘要、输入、输出、时序用量、原文和来源。输入输出及原文按需读取。可定位回过程，也可从成员返回原主会话位置。
5. 回放仅控制阅读进度，支持暂停与单步。浏览历史期间的新数据只提示，不抢走当前记录或移动历史窗口。
6. 复制当前位置链接保留任务、成员、读法、事件、元数据搜索、错误筛选和明确 UTC 时间窗口。旧会话与团队链接可以继续定位。
7. 数据接入解释本地日志、代理、CDP、Frida、文件导入的用途与支持条件。可在页面启停共享本地监听器，并使用既有代理控制。

## 借鉴 DSH 的部分

参考本地 DSH 源码中的会话内 Trajectory、单条 Inspector、按身份定位、子 Agent 导航及正文懒读取。没有运行 DSH 或直接复制其应用结构。源码版本及逐项依据在 [dsh-reference.md](dsh-reference.md)。

本项目增加任务读取投影，将原生主/子会话与离线导入放入统一入口，同时保留来源边界、分页窗口和证据完整性提示。采集方式没有变成任务类型。

## 当前运行状态与使用边界

服务监听本机 `127.0.0.1:4173`。普通重启默认关闭自动监听和代理。2026-10-25 验证结束时曾恢复此前授权的监听；2026-10-27 增量按普通启动保持监听与代理关闭。停止监听不会停止外部 Agent。

主会话是当前任务的锚点。没有明确父子证据的会话继续独立展示；不按标题或时间猜测关系。记录状态来自日志，不等于 Agent 当前在线。缺少任务指派、成员通信、完整模型请求或时间信息时，不推断完成率、通信图或关键路径。

## 继续跟踪的增强与验收

时间导航、按轮次/步骤/可识别尝试阅读、工具输入输出关联已在 [2026-10-27 增量](time-process-20261026.md) 落地。该报告也记录了最终验证与当前运行状态；以下更广范围继续跟踪：

- 将多个底层事件归并为统一逻辑活动的完整投影、错误筛选的祖先上下文、跨过滤目标的临时揭示与恢复。
- 全新独立的待关联遥测收件箱；目前复用既有来源与请求关联能力和兼容入口。
- 原生格式的一般性文件导入；当前仍使用已支持的 TraceLog JSON/归档格式。
- 窄屏真实设备、亮暗主题与双语的完整浏览器矩阵，以及严格 30 秒 API 请求计数；代码含响应式和双语，但不冒充已完成全部现场验收。
